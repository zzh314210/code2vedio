# 鹈鹕先生的视频站

The artwork is adapted from the user-supplied `/data/pelican-cycling.html` on
2026-10-20. The orange hat and scarf, long bill, feather details and green bicycle
are retained directly from its SVG rider. Pedals and feet use a fixed pose from
the reference animation so the standalone artwork has no JavaScript dependency.

- `pelican-cycle.svg`: full rider for the site and login logo.
- `pelican-profile.svg`: the same head and neck, cropped for small browser icons.
- Apple/app PNGs use the full rider; the ICO uses the profile for small-size clarity.

The lower-left slogan uses the existing abstract Layers icon, not a pelican.
No external image service or new third-party artwork is used.

# Model provider icons

Source: https://github.com/lobehub/lobe-icons
Package: @lobehub/icons-static-svg, version 1.95.1 (MIT; see LICENSE).

Only the selected vendor SVGs are included and served locally. Logos identify the model provider; they do not imply endorsement. Unknown model names use a neutral icon.

The white letter in the Kimi color mark is rendered in dark ink for contrast on this site's light cards; its blue accent and geometry are preserved.

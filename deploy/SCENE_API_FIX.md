# 动画组件调用修复与任务恢复（2026-10-20）

## 原因

生产任务在 `section_1` 首幕调用 `self.sketch_shape("rounded_rect", ...)`，同时传入 `corner_radius`、`fill_color`、`stroke_color`、`stroke_width`。这些是 Manim 圆角矩形的参数；项目手绘适配器不支持 `rounded_rect`，使用的颜色参数是 `color` 与 `fill`。

初次渲染及三次模型修复先后报 `unexpected keyword argument 'corner_radius'` 和 `unexpected keyword argument 'fill_color'`。原校验只检查 Manim 类名、危险语法和主题约束，没有检查项目自定义绘图方法的签名；通用报错也隐藏了最终原因。

## 变更

- `scene_api.py` 静态读取当前项目运行时快照，提取自定义绘图方法的实际参数、默认值和手绘图形类型。不会在网站后台导入 Manim，也不执行运行时代码。
- 生成和修复提示词均附上实际接口，明确圆角矩形使用 `RoundedRectangle`。
- 模型返回代码时检查缺失参数、不支持的参数、重复传参和无效图形类型，进入现有结构化输出修正流程，避免同样错误消耗 Docker 渲染重试。
- 旧项目按自己的接口快照校验，缺失的新方法不会被误认成可调用方法。
- 修复次数耗尽时显示章节名称、修复次数和最后一条错误原因。

## 验收和原任务恢复

- 组件接口回归、渲染故障归因、九种题材与主题组合、运行时快照保护检查通过。

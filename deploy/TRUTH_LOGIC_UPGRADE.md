# 供应商思考协议与真假话可视化升级

2026-10-22。本轮以两条120秒、1920×1080、30fps成片及真实网页任务验收。线上运行只依赖配置的模型接口、本地渲染与免费配音，不依赖 Codex 或 Claude 编程代理。

## 模型配置

个人配置与管理员平台模型共用供应商选择、地址、密钥、型号、思考开关与强度。默认开启，强度 `max`。可手动填型号或获取列表。供应商指**接口协议服务商**：托管的 DeepSeek/Kimi 使用托管服务协议，而不是按模型品牌猜协议。

| 供应商 | 请求适配 | 产品 Max 的实际处理 |
| --- | --- | --- |
| 自定义兼容 / 阿里云托管 | Chat Completions，按托管型号注入参数 | DeepSeek/Kimi 发送 max；Qwen 3.8 发送 xhigh；未知兼容别名单独标记未核实 |
| DeepSeek 官方 | `thinking.type`、`reasoning_effort` | 发送 enabled / max |
| Kimi 官方 | K3仅发送 `reasoning_effort`；旧型号用 `thinking.type` | K3支持 low/high/max，默认max；K2.6等不伪造强度字段 |
| OpenAI | Responses `reasoning.effort` 或兼容协议 `reasoning_effort` | 已知旧型号映射 high / xhigh；未知型号保留 max；不支持推理的旧型号明确拒绝 |
| Claude 官方 | 原生 Messages、专用认证头 | 新型号 adaptive / output_config；旧型号换算预算，并给正文保留输出空间 |
| 豆包 | `thinking.type`、`reasoning_effort` | max 映射 high |
| 智谱 | `thinking.type`，GLM 5.2/5.3加 `reasoning_effort` | 最高max；旧型号只发开关；5.3不允许关闭 |
| MiniMax | `reasoning_split`；M3.1 Flash加 `reasoning_effort` | M3.1 Flash发送max；M2.x固定策略；不支持关闭时明确报错 |

协议实现在 `src/provider_protocols.py`。每次调用记录请求强度与**发送映射策略**；这不是供应商回传的实际档位确认。平台账单可查看，不保存私有思考正文。自备 API 不扣站内余额，也不进入平台收费流水。失败调用如果上游返回 usage，仍保留真实用量，不伪造为零。开启最高思考会增加耗时与 token，不等于正确性保证。各型号官方来源与正反例实测见 [PROVIDER_PROTOCOLS.md](PROVIDER_PROTOCOLS.md)。

## 从输入到成片

1. **冻结任务。** 保存题干、素材、配置与可信编译器/渲染器快照。输入指纹锁定版本；旧任务继续使用原快照。
2. **模型抽取。** 只提取逐字原话、已给条件和受限逻辑 DSL。禁止补充“只有一人参与”、改变说话人或润色题干。
3. **独立语义核对。** 另一次模型请求逐句比较原话与逻辑表达式。必须 equivalent=true 且 issues=[]，并绑定证明 hash；缺少或错配凭据不能继续。
4. **程序穷举。** Python 枚举全部候选世界，计算每句真假、真话人数、矛盾/同义关系与答案。无解、多解或不属于支持题型时拒绝，不硬套讲解。
5. **证明编译大纲与分镜。** 固定六幕：读题、找关系、推导/假设、枚举、回代、总结。旁白、人物标记、真值表都来自同一证明；语义文本只读，可调时长与读题停顿。
6. **免费配音与实测时序。** Edge TTS；按实际音频和逐句字幕安排画面，先读题再揭示结论。
7. **图解渲染。** 新增 Pillow + FFmpeg 引擎，1080p、30fps、两编码线程、流式写帧。人物、原话卡片、矛盾连线、分支、真值表和高亮由确定性代码绘制；本题不让模型临时生成 Manim Python。原 Manim 管线继续供其他模板使用。
8. **视觉审核。** 使用真实视觉模型检查人物/真假标记、字幕、遮挡与讲解一致性。失败阻断制作，不允许通用“修代码”绕过逻辑证明。练习初版的真假标记提前揭示已被审核拦截，修为两种假设并列、当前状态标待定。
9. **合成与终检。** 音视频/字幕轨、六幕完整性、实测时长、每幕 proof/narration hash 与最终 SHA256 均生成凭据。两条样片另做 FFmpeg 完整解码与每幕三个时刻的18帧抽查。

Hash 验证防止版本交接错乱，不能证明自然语言翻译一定正确；独立语义核对与视觉抽查也不能代替用户最终审阅。

## 明确支持的题型

- 四人甲乙丙丁、题干明确恰有一人做事、恰好一句真话、有互补矛盾对且唯一解的题；候选范围不明确排除外人时必须包含“其他人”。
- 四人各自可能参与、甲丁同义、两真两假、选项问谁必然参与的受限题型；枚举16世界，并检查“一人”的包含/恰一解释下答案是否稳定。

当前不是所有真假话题的通用解题器。自指、任意量词、复杂多变量以及不符合上述结构的题不继续渲染。当前模板仅手绘横屏，100–180秒，避免四个人和原话被压成不可读的竖屏。证明绑定模板暂不支持 AI 自由改写结论或修改成片；请求在模型调用前明确拒绝。其他模板保留原有编辑功能。

```bash
.tmp/release-frame-api -root /data/code2vedio -upgrade-reasoning-defaults
```

该命令补齐旧平台目录的供应商与默认思考策略、提高过小输出预算；保留密钥、价格、型号与显式关闭思考的配置，并写管理员审计。可重复执行。只重启本项目API和worker；不改sub2api。回滚恢复同一次备份的源码/二进制/静态资源；若回滚配置，需在停止写入后连同加密密钥恢复配套数据库。

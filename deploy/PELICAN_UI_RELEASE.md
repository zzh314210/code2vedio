# 鹈鹕品牌、模型选择与网络恢复 · 2026-10-20

本版延续原有创作布局，网站名称改为「鹈鹕先生的视频站」。原创骑车鹈鹕 SVG 统一用于侧栏两处标识、登录页面、浏览器 favicon、手机收藏和 Web Manifest。顶部仅保留余额与用户入口，退出登录移至「账号与安全」。

## 模型与余额

- 新账号优先使用平台模型；已保存的自备 API 选择保持不变。平台模型需首次预付至少 5 元，自备 API 无需站内预付。
- 平台模型选择改为带厂商图标的大卡片，显示真实模型名称与单价。厂商图标来自 MIT 许可的 LobeHub Icons，全部本地提供，来源及许可见 `web/public/model-providers/`。
- 当前可用默认 ID 为 `deepseek-v4.1-flash-1017` 和 `qwen3.8-flash`；服务商列表没有 `1013`，未使用不可调用的模型名。
- 模型弹窗仅展示可用余额、每条视频约 1 元的参考预算及免费 TTS；创作页仍按模型和时长展示费用区间。这些均为估算，实际费用按真实用量结算。
- 删除模型弹窗和创作费用预估旁的「先充值 5 元 →」。充值入口位于「余额与账单」；用户实际使用平台模型且余额不足时仍会提示。
- 自备 API 在 Go 授权与结算、Python 计费客户端和用量文件三个入口排除：不预占、不扣款、不新增本地调用记录或账单。旧版零费用自备记录不再参与用户/管理员统计，也不能人工补扣。历史文件和数据库原始记录保留，不做破坏性清除。

## 交互与错误恢复

AI 剪辑的目标时长、画面比例及选段动效采用 Radix Select，支持鼠标、触屏、方向键、Home/End 和 Escape。选项有图标、用途说明和选中状态；窄屏下控件和菜单均在视口内。

`Load failed` 已通过浏览器故障注入复现：一次 `/api/jobs` 读取失败写入全局错误，后续成功轮询没有清除，切换账单页仍显示。修复包括：

- GET/HEAD 连接故障或 502/503/504 最多尝试三次，每次读取有超时；写入、扣费和生成请求不自动重试。
- 读取错误按作品列表、模型配置和账单分别保存，成功后清除；切页不会带入无关错误。
- 轮询防止重叠；取消时终止未完成读取；网络恢复或窗口重新激活时更新数据。
- 模型弹窗可以重试配置和模型目录读取；重试目录不会覆盖尚未保存的自备 API 输入。
- 网络异常使用中文说明；写操作失联会明确说明结果尚未确认，提示先查看结果，避免重复提交。

## 验收与发布

自动验收覆盖零余额自备 API 不进入本地流水、平台计费保留、历史自备记录过滤、工作区隔离及成片修改。Go 测试、Python `scripts/usage_meter_smoke.py` / `scripts/revision_api_smoke.py` 和 TypeScript/Vite 构建通过。`node scripts/web_request_smoke.mjs` 验证读取恢复、重试次数、写入不重放、取消请求及登录/余额事件。

Chromium 与 WebKit（Safari 同类内核）均已通过桌面、平板及手机验收；WebKit 依赖解包在项目临时目录，未安装或改动系统包。浏览器证据保存在忽略目录 `.tmp/pelican-acceptance/`：瞬时与持续断网恢复、页面错误隔离、配置持久化、键盘选择、390/768/1440 像素布局及退出登录。品牌 PNG/ICO 均由原创 SVG 渲染；不依赖外部图片接口。

本次只改模型配置、账户管理和计费，保留既有创作布局、视频模板、样片、剪辑及成片修改功能。参考 `/data/sub2api/backend/internal/service/usage_service.go` 的事务结算、`admin/user_handler.go` 的幂等余额调整以及 `usage_handler.go` 的用户隔离与分页筛选，在现有 Go/SQLite 账户服务内实现。

## 用户行为

- 首页仍可直接浏览创作面板；实际个人操作需登录。
- 「模型配置」在独立弹窗内打开，关闭后保留创作草稿，不占主面板。
- 账号加密保存配置，Cookie 仅记录首次提醒。已保存自备 API 选择不会被默认平台覆盖。
- 新账号可直接选平台模型，无需填 Key；默认生成 `deepseek-v4.1-flash-1017`、默认审核 `qwen3.8-flash`。请求的 `1013` 不在实际模型列表中，使用已验证的 `1017`。
- 平台首次使用需管理员确认实收预付至少 5 元；注册零余额。5 元是余额，不是每条视频固定费用。已有自备 API 配置保留且不收站内模型费。
- 「余额与账单」提供充值与调账账单、全部余额变动和模型调用分页。每笔展示输入/输出/缓存、请求/作品编号、用途/管线阶段、耗时、响应编号、历史单价、精确费用、实际扣款及状态。
- 管理后台可以创建普通用户、停用账号、增减余额，配置平台模型、密钥、默认项、价格与充值说明，并查看所有账号的调用。
- 用户看到预估区间，实际费用取决于真实用量和重试次数；预估不是收费上限。

## 资金与隐私边界

- 任务保存加密模型及价格快照；改价只影响新任务。同一任务每次请求独立锁定适用峰谷价。
- 文本按输入 UTF-8 字节上界加协议余量预占；含图片按模型完整输入上限预占；都加最大输出上限。并发预占和扣款原子执行，禁止透支。管理员减少余额也不能占用预留资金。
- 实际输入/输出/缓存三项按快照计算；以微元保存成本，同一任务累计按分向上取整扣款。重复授权/结算/充值凭证不重复处理。
- 自备 API 无需站内预付，永不收取站内模型费用，也不产生站内调用记录、余额预占或流水；费用与用量由用户的 API 服务商提供。免费配音不收费。未新增制作、渲染、带宽或存储费。
- 明确被服务商拒绝的请求释放预占。连接中断/缺少有效用量时保留预占，显示待核对；管理员依据服务商原始账单补录用量，核对依据与账本在同一事务审计。进行中的请求至少 15 分钟后才允许人工接管核对。
- 密钥加密存储；公开目录不含服务地址或密钥。历史凭据、用户文稿、模型响应正文不进入账单。历史版本生成用量仍保留在对应作品的 usage.jsonl；本版仅平台模型的统一账单记录从启用此版本起入库，不追扣历史任务。旧版零元自备 API 记录不再参与账单展示、统计或人工核对。
- 当前充值为管理员确认收款后入账，未接入在线支付。后台可填写实际收款联系方式；默认文案如实说明联系管理员。

# 左下角鹈鹕骑行（2026-10-20）

> 历史版本记录。后续根据用户反馈移除了左下角插画、加速和铃声，只保留三行文字；骑行动画改在左上角品牌中显示。当前实现及验收见 `CREATION_POLISH_ACCEPTANCE.md`。

正式站 `https://vedio.myaihub.asia` 于 08:42 UTC 更新前端，预览站使用同一构建。

## 交互

- 沿用用户提供的 `/data/pelican-cycling.html` 插画与腿部运动算法：脚踏、车轮、身体起伏和围巾联动。
- 「加速」切换为 2.2 倍速度，再点恢复；「按铃」播放本地合成的短车铃，显示「叮铃」反馈。点击鹈鹕可暂停/继续，支持键盘。
- 配文严格使用「和鹈鹕先生一起，把想法变成看得见的视频」。
- 不自动播放声音；铃声结束后挂起音频上下文，重复点击有节流，组件卸载时释放音频。
- 动画最多约 30 帧/秒，不触发逐帧 React 渲染。页面后台、侧栏隐藏或画面离开可视区域时停止；系统开启减少动态效果时默认静止，可手动播放。
- 900px 及以下沿用原侧栏隐藏策略。较矮桌面缩小插画，保持管理员导航可用。

## 用户使用路径

访客直接进入创作面板，可以选择题材、风格和观看真实示例。实际生成、素材读取及个人操作时登录；登录前输入的草稿与本地文件保留在当前页面内存，不自动提交。注册、个人作品、账户余额与模型配置由 Go 提供，Python 仅承担私有工作队列与渲染。

- **创作视频**：填写要求或上传素材 → 编辑大纲 → 编辑分镜 → 生成、预览、下载。自动完成选项明确跳过人工确认。实际管线进度、预估耗时和离开页面的说明均已接入。
- **笔记放映室**：上传笔记即可开始，默认三分钟，生成知识地图、可视化串讲、易混点与带答案的回忆题。笔记与普通创作各保留自己的草稿。
- **AI 剪辑**：上传视频 → 模型理解画面和本地转写 → 查看/调整选段与字幕 → 确认导出。优先提供30–120秒直播带货切片；另有游戏高光、叙事纪实及精华速剪。
- **修改视频**：完成的创作作品可用自然语言生成独立新版，默认先确认修改后的分镜，原片与素材保持不变。可切回原版比较。
- **AI 帮我看看**：用户主动点击才调用视觉模型。使用真实分镜时刻抽帧、时间/幕次标注及建议证据复核；最多四条可编辑建议，支持一键填入修改要求。建议仍由用户决定是否采用。

保留已认可的双栏布局、完整面板边框、56px页眉和小型题材卡。三阶段仅当前阶段抬起强调；风格顺序及默认均为深空演示、清晰图解、手绘课堂。模型配置位于“一分钟使用引导”旁。每账号/浏览器的引导仅首次自动出现，清除站点cookie后可再次出现。修改弹窗固定保留底部操作，320px宽度可用。

## 题材质量约束

| 题材 | 实际采用的约束与组件 |
| --- | --- |
| 知识讲解 | 每幕一个问题，先演示再解释；月相采用真实照明几何，区分月相与月食。 |
| 历史地图 | 真实经纬度/陆地投影、日期事件联动、近邻地点放大；叙事关联线不冒充行进路线，结尾考点与回忆题。 |
| 数学 | 多项式数值、曲线、割线和切线同步计算；公式独立分步，明确非零等条件，图形不出界。 |
| 单词故事 | Google Noto 矢量角色、连续动作；明确原创联想并非词源，词义/例句/回忆答案分开。 |
| 微纪录片 | 有来源的真实照片、连贯慢镜与因果图解；照片和动画明确区分。 |
| 产品介绍 | 使用实际上传产品图或截图，完整主体、少量标签、克制动效；不虚构功能、折扣和效果。 |
| 笔记复盘 | 同一知识框架持续回扣、动态算例、易混对照；承诺三道题就必须实际给出三组问答。 |
| 带货剪辑 | 完整语义、同一商品、价格/规格/优惠门槛保留；选段和导出前复核，不以高音量代替卖点。 |

完整画布组件拒绝模型重复叠字；不存在的Manim构造器、超长标题、超时旁白等在渲染前校验。项目快照不可在恢复时被新组件偷偷覆盖。帧时钟与实测配音对齐，保留真实回忆停顿。画面审核拒绝时追加同证据核实，保存两次意见；真实问题仍阻止发布。

## 实现与运行边界

线上只依赖配置的模型API、本地FFmpeg/Manim/语音识别与免费配音，不调用Codex/Claude。调研与实际取舍见 [RESEARCH_DECISIONS.md](RESEARCH_DECISIONS.md)。新模板测试使用 Kimi K3 → DeepSeek V4.1 Flash1017，视觉 DeepSeek V4.1 Flash → Qwen3.8 Flash；每任务冻结配置。

免费搜索只保留已验证正文的百科及个人素材库，不消耗模型额度；不稳定的搜索源已停用。模型生成、规划、视觉审核会消耗用户配置模型的额度。Edge免费配音仍依赖外部服务可达；不接额外付费素材或语音渠道。

当前服务器按资源限制单任务服务，离开页面可以继续执行，但不是无限并发服务。带货输入每份最多15分钟、总计30分钟，不声称一口气分析数小时直播。公开带货示例是流程演示，真实主播素材仍需用户核对商品、价格、字幕和版权。

余额、官方价格快照、预占/实际usage/缓存token结算、防重流水已实现，**生产自动扣费保持关闭，用户自带Key不重复收取模型费**。平台模式需要核对实际服务单价并启用配置；按官方token成本无法覆盖全部渲染/带宽/存储成本。详见 [USER_SYSTEM.md](USER_SYSTEM.md)。

开放API包含创作输入、规划确认、状态轮询、结果下载、剪辑与修改，见 [API.md](API.md)。部署及回滚见 [README.md](README.md)，本次发布最终结果见 [RELEASE_ACCEPTANCE.md](RELEASE_ACCEPTANCE.md)。

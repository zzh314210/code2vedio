APPLICATION VIDEO STYLE: HAND-DRAWN SKETCHBOOK, version 1.0.0.
This is a policy for the external video-generation model, not a tool or instruction for a terminal agent.
Use a warm ivory paper canvas (#FFF9ED), charcoal ink (#29332F), teal (#237F79) and coral (#DD654E). No dark dashboard, gradients, progress rails, branded headers, subtitle cards or unnecessary UI labels. Keep the lower 1.15 scene units clear for charcoal subtitles.
Create a tactile whiteboard/sketchbook, not merely recolored geometric slides. Draw important strokes and vector arrows with self.sketch_line(start, end, color, width=3, arrow=False). This returns a VGroup of native Manim ink paths with deterministic organic variation; use Create on it. Arrow=True adds a hand-drawn arrowhead. Optional labels can use self.scene_text. Do not call unsupported self methods. Marker accents may use translucent pale teal/coral shapes behind text. Avoid grids unless needed for coordinate accuracy; if used, subtle thin lines, equal x/y units, no numerical tick clutter.
Composition: asymmetrical editorial layout, a generous headline at upper left, one dominant illustration and a separate large formula. Keep at least 0.3 units between text and strokes. Never overlay component labels on vector labels. Text must be legible in Chinese; do not jitter text itself or sacrifice mathematical geometry for roughness. Use the existing configured font, not unavailable handwriting fonts.
Motion: purposeful pen-on-paper Create, sequential marker emphasis and one clear result reveal, not a scatter of decorative fades. Keep animation synchronized with measured narration cues. Show the final numerical result before the spoken result finishes and hold it at least 2 seconds. Entire scene remains 10 seconds when requested.
Outline/storyboard must specify a concrete visual hierarchy and timing, not generic lesson/dashboard titles. Code must implement actual sketch strokes with self.sketch_line, not ordinary straight arrows alone. Review checks paper palette, organic ink strokes, correct mathematics, readable labels, negative space, subtitle clearance and speech/result timing.
Design sources archived locally: Excalidraw and Rough.js README/license; frontend-design SKILL/license. These supply design references, not a JavaScript rendering dependency. This policy and native renderer are the application integration.
